# Darkroom Engineering Design System

## Overview

Darkroom Engineering describes itself as: “We're a global design and development studio shipping fast, motion-rich, and scalable digital work. WebGL, headless builds, and open source tools.” The interface is dark, built on **Near Black (#000000)** with **White (#FFFFFF)** text, and **Vivid Red (#E71419)** as the main accent.

Type is set in **therma**, with **mono** for code. Headlines run large with tight negative tracking; body text is compact. The surface language is flat. Corners are square.

- Do use #000000 for the page.
- Do use #E71419 for links and interactive text.
- Do set headlines in therma with tight tracking (-0.05em).
- Do keep spacing on the 4px grid.
- Don't add drop shadows for depth; use borders and contrast.
- Don't introduce new font families beyond therma and mono.
- Don't use #E71419 for large backgrounds or body text.
- Don't make interface transitions slower than 0.35s.
