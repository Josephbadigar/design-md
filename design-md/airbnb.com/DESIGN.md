# Airbnb Design System

## Overview

Airbnb describes itself as: “Get an Airbnb for every kind of trip → 7 million holiday rentals → 2 million Guest Favourites → 220+ countries and regions worldwide” The interface is light, built on **White (#FFFFFF)** with **Charcoal (#222222)** text, and **Vivid Red (#FF385C)** as the main accent.

Type is set in **Airbnb Cereal VF**. Headlines run large; body text is 14px. The surface language is flat. Corners are mostly 8px.

Measured from [airbnb.com](https://www.airbnb.co.in/?locale=en) on October 21, 2026 at 1440×900 and 390×844 from 125 rendered elements. Values are computed styles from the live page, not the original source files.

## Colors

The palette has 6 roles.

- **White (#FFFFFF):** Page background, seen 1 time. Token `background`, CSS `--palette-loading-material`.
- **Charcoal (#222222):** Primary text and headings, seen 7 times. Token `on-surface`, CSS `--palette-bg-slider-track-active`.
- **Mist (#F2F2F2):** Raised areas one step from the page, seen 4 times. Token `surface-container-low`, CSS `--palette-bg-quaternary`.
- **Mist (#EBEBEB):** Cards and panels, seen 80 times. Token `surface-container`.
- **Vivid Red (#FF385C):** Brand accent (CSS variable), seen 1 time. Token `primary`, CSS `--palette-bg-primary-core`.
- **Near Black (#000000):** Text and icons on primary. Token `on-primary`.

## Typography

**Airbnb Cereal VF** carries the whole interface. Fallback stack: `Airbnb Cereal VF, Circular, -apple-system, BlinkMacSystemFont`.

- **headline-display:** Airbnb Cereal VF 28px at weight 700, line height 1.43 (26px on mobile). Page title (h1).
- **body-md:** Airbnb Cereal VF 14px at weight 400, line height 1.43. Body text.

## Do's and Don'ts

- Do use #FFFFFF for the page and lift surfaces in small steps: #F2F2F2, #EBEBEB.
- Do use #FF385C as the brand accent: header, logo and key highlights.
- Do reuse the measured spacing steps (5px, 12px).
- Do use 8px corners on most elements; larger surfaces also use 4px.
- Don't add drop shadows for depth; use tonal surfaces.
- Don't introduce new font families beyond Airbnb Cereal VF.
- Don't use #FF385C for large backgrounds or body text.
- Don't make interface transitions slower than 0.25s.

## Motion

Interface transitions are quick: 0.25s.
