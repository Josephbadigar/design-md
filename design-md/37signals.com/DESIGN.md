# 37signals Design System

## Overview

37signals describes itself as: “A catalog of ideas — signals — that drive us.” The interface is light, built on **Vivid Orange (#F87917)** with **Near Black (#000000)** text, and **Vivid Orange (#F87918)** as the main accent.

Type is set in **Lab Grotesque**. Headlines run large with tight negative tracking; body text is compact. The surface language is flat. Corners are square.

## Do's and Don'ts

- Do use #F87917 for the page.
- Do keep text in 2 levels: #000000, #FFFFFF.
- Do use #F87918 as the brand accent: header, logo and key highlights.
- Do set headlines in Lab Grotesque with tight tracking (-0.01em).
- Do reuse the measured spacing steps (11.18px, 25.8px).
- Don't use #FFFFFF for body text; it reaches 2.7:1 on #F87917. Keep it for large text or metadata.
- Don't add drop shadows for depth; use borders and contrast.
- Don't introduce new font families beyond Lab Grotesque.
- Don't use #F87918 for large backgrounds or body text.
- Don't make interface transitions slower than 0.2s.
