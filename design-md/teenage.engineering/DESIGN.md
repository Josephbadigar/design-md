# teenage engineering Design System

## Overview

teenage engineering describes itself as: “teenage engineering creates high quality, well designed, electronic products for all people who love sound and music.” The interface is dark, built on **Near Black (#000000)** with **Mist (#F1F2F2)** text and almost no color: actions are carried by contrast, not hue.

Type is set in **te-20**. Headlines run large; body text is 16px. The surface language is flat. Corners are square.

## Do's and Don'ts

- Do use #000000 for the page.
- Do keep text in 2 levels: #F1F2F2, #E5E5E5.
- Do let contrast carry emphasis; primary actions use #F1F2F2 on #000000.
- Do reuse the measured spacing steps (14.69px).
- Don't add drop shadows for depth; use borders and contrast.
- Don't introduce new font families beyond te-20.
- Don't add saturated accent colors; the measured palette is almost entirely neutral.
- Don't make interface transitions slower than 0.2s.
